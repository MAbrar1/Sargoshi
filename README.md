# Sargoshi

A private Android messenger: end-to-end encrypted chat and calls, a Private Vault, encrypted backup, on-device AI, built in Flutter, Kotlin and Rust. Specification: `docs/blueprint/Sargoshi-Final-Blueprint-v5.md`.

## Working on it
- Read `AGENTS.md`, then `docs/ledger/PROGRESS.md`.
- The single quality command: `node tools/gate.mjs` (add `--full` for Flutter/Rust checks, `--phase Pxx` for a phase gate).
- Progress per feature: `node tools/ledger.mjs status`.
- Layout rules: `docs/ledger/PROJECT-TREE.md`. Honesty rules: `docs/ledger/REALITY.md`.
- Local setup: `docs/runbooks/LOCAL-DEV.md`.
