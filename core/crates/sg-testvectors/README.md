# sg-testvectors
Known-answer tests for every primitive wrapped by `sg-crypto`.

- `vectors/*.txt` are generated by `node tools/gen-vectors.mjs` from Project Wycheproof and NIST ACVP at pinned commits; `vectors/SOURCES.md` records the upstream commits and file hashes.
- `tests/*.rs` run each vector through the public API of `sg-crypto` and fail on any mismatch.
- The `deterministic-kat` feature of `sg-crypto` is enabled only here, to reproduce NIST ML-KEM encapsulation vectors.
