# Sargoshi v5 package

- `Sargoshi-Final-Blueprint-v5.pdf` and `Sargoshi-Final-Blueprint-v5.md` are built from one source. Same text, same tables, same figures.
- `figures/` holds Figures 1 to 13 as SVG. The Markdown links to them, so keep the folder next to the .md file. Text in figures uses Inter, Plus Jakarta Sans and Noto Naskh Arabic (install them to view the SVGs outside the PDF).
- `logo/` holds the logo kit: mark, lockups (outlined text, no fonts needed), app icon, Android adaptive layers, notification icon, Vault mark, splash, and PNG exports.
- `design-tokens.json` is the token file from Section 6.14.

Read-only. Never read the whole blueprint: use the line ranges named in docs/prompts/Pxx. Section line index: docs/spec-data/section-index.csv.
